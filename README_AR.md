# تعليمات تشغيل منصة محراب القرآن محلياً 🚀

أهلاً بك! لتشغيل هذه المنصة على جهازك الشخصي والاستفادة من كافة ميزات الذكاء الاصطناعي والتحليل البرمجي، يرجى اتباع الخطوات البسيطة التالية:

## المتطلبات الأساسية
- تثبيت **Node.js** (الإصدار 18 أو أحدث). يمكنك تحميله من [nodejs.org](https://nodejs.org/).

## خطوات التشغيل
1. **فك الضغط** عن الملف الملحق في مجلد خاص.
2. **افتح واجهة الأوامر (Terminal/CMD)** داخل المجلد.
3. **تثبيت المكتبات اللازمة:**
   ```bash
   npm install
   ```
4. **تشغيل المنصة:**
   ```bash
   npm start
   ```
5. **افتح المتصفح** وتوجه إلى الرابط التالي:
   `http://localhost:3000`

## إعداد مفتاح Gemini API
لكي يعمل المساعد الذكي "مداد الرحمن"، يجب توفير مفتاح API:
- **الطريقة الأولى:** أنشئ ملفاً باسم `.env` في المجلد الرئيسي وأضف السطر التالي:
  `GEMINI_API_KEY=YOUR_API_KEY_HERE`
- **الطريقة الثانية:** أدخل المفتاح مباشرة داخل المنصة عبر أيقونة المفتاح (🔑) في الشريط العلوي.

## ملاحظة هامة
لا تفتح ملف `index.html` مباشرة في المتصفح بسحبه، لأن المتصفحات تمنع تشغيل تطبيقات الويب الحديثة بهذه الطريقة لأسباب أمنية. يجب دائماً استخدام أمر `npm start`.
